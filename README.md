# .github

Default community health files for the public repositories on the [CompleteDotTech](https://github.com/CompleteDotTech) account. GitHub applies them to any public repository here that does not have its own copy.

This is one person's account. Most of its public repositories are forks of upstream projects, so issues about upstream behaviour belong upstream. The personal profile page lives in the separate `CompleteDotTech` repository, not here.
