# Security policy

Please do not open a public issue for a security problem.

## Reporting a vulnerability

1. Use the repository's private "Report a vulnerability" form on its Security tab, if it is shown.
2. If it is not, use the contact form on [complete.tech](https://www.complete.tech/#contact) and say only that you have a security report, with the repository name. Details can follow once there is a private channel.

Please do not include real credentials or personal data in a report.

## Forks

Most public repositories on this account are forks. If the problem is in upstream code, report it to the upstream project as well; it cannot be fixed here.

## What to expect

This is one person's account, and many repositories are prototypes. Reports are handled on a best-effort basis with no guaranteed response time. Credit is given on request once a fix is made.
